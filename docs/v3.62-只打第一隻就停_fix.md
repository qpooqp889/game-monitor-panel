# v3.62 修復：只打第一隻 BOSS 就停止

## 根因
擊敗 BOSS 後僅等 1.5s 就重跑 Loop，但遊戲 DOM 從結算畫面切回世界王頁籤需要 2-3s。此時 Loop 掃描 `.wb-card[data-boss]` 為空 → `scoredList.length===0` → 觸發 `RestoreFarm` 恢復掛機 → 腳本停止。

- `setTimeout` 1500ms → 3000ms

### 2. HP<20% 提早離開：同步
- `currentIdx = idx+1`
- `setTimeout` 1500ms → 3000ms

### 3. scoreList 為空：不恢復掛機
- 移除 `__wbBossAutoScriptRestoreFarm()` 呼叫
- 加 `__wbEnsureWBTab()` 嘗試切頁籤

### 4. hunt list 為空：不恢復掛機
