# v3.62 速度優化 + 只打第一隻修復

## 任務目標
1. 進入 BOSS 後自動攻擊反應太慢 → 加速

3. 修復「只打第一隻就停」問題

## v3.60 速度優化
| 環節 | 舊 | 新 |
|------|-----|-----|
| 進入 BOSS → 自動攻擊 | 等 500ms | 立即觸發 |
| 擊敗後離開 | selectChar[0] + 3s | #br-lobby click + 500ms 備援 + 1.5s |
| HP<20% 離開 | toLobby + 3s | #br-lobby + toLobby + 1.5s |
| 掉落檢測 | 500ms | 200ms |
| MonitorBossHP | 第一次等 500ms | 立即執行 _doCheck |

## v3.61 Debug Export 修復
- `__wbDebugFlush` / `__wbDebugExport` 改用 `window.__gmStorageGet/Set` relay
- 遊戲頁面 context 中 chrome.storage 不可用，須走 relay

## v3.62 只打第一隻就停修復
**根因**：擊敗後 1.5s 就重跑 Loop，DOM 來不及切回世界王頁籤 → scoredList 空 → RestoreFarm → 停

**修正**：
| | 舊 | 新 |
|------|-----|-----|
| currentIdx | reset = 0 | idx+1 跳下一位 |
| 擊敗等待 | 1.5s | 3s |
| scoredList 空 | RestoreFarm + 10s | 5s + EnsureWBTab |
| hunt list 空 | RestoreFarm + 10s | 只 retry, 不恢復掛機 |
